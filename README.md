# Clínica Sorriso Prime — Landing Page
Abra a pasta no VS Code e rode `index.html` com a extensão **Live Server** (ou dê duplo clique no arquivo).

## Antes de publicar (dados reais)
1. `js/main.js`: troque `WHATSAPP_NUMBER` pelo número real (formato 5511999999999) e ajuste a mensagem.
2. Procure por `[colchetes]` e pelos trechos amarelos tracejados (`.ph`) no `index.html`: depoimentos, FAQ, telefone, endereço, horários, CRO.
3. Contato: troque o bloco `.map` por o iframe do Google Maps.
4. `<head>`: descomente e preencha `og:url`, `og:image` e o JSON-LD (Schema.org Dentist) quando tiver os dados.
5. Fotos (opcional): coloque em `assets/images/` em WebP, com `width`/`height` e `alt`.
